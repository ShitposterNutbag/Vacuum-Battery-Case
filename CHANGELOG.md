# CHANGELOG

## Version 2

- Preserved the V1 enclosure outer envelope, split height, wall thickness, screw post layout, and flat print orientations.
- Preserved the existing fixed battery reference dimensions and the 0.8 mm per-side battery cavity clearance.
- Replaced the earlier small charging-port placeholder with an oversized rectangular front-wall opening for the charging board and USB connector.
- Kept screw holes cylindrical because they are functional fastener clearances, not board/interface placeholders.
- Added an oversized rectangular top opening for power-button access.
- Added an oversized rectangular top LED visibility slot for the indicator area.
- Left the board, USB, button, and LED openings intentionally oversized where exact locations could not be reliably determined from the scan/reference photos.
- Kept the enclosure as separate printable top and bottom STL exports.
- STEP export was not regenerated because no STEP-capable CAD exporter is available in the current environment.
