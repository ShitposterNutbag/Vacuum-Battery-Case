# RealityScan Reference Mesh

## Purpose
This mesh is a reference only. It is not intended to become the final CAD model.

## Known Scan Artifacts
- Piece of tabletop attached to the bottom of the mesh.
- Tape protruding from the side of the battery pack.
- Minor photogrammetry noise and rough surfaces.

## Preserve
- Overall battery pack dimensions.
- Cell locations.
- PCB locations.
- USB-C charging board.
- LEDs.
- Power button.

## Goal
Use the cleaned scan as a reference for creating a fully parametric battery enclosure.
