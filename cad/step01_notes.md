# Step 01 — Battery Cell Block Only

## Scope

This step contains only six separate cylindrical 18650 cells. It does not include a case, box, walls, enclosure, holder, carrier, PCB, connector, wiring, or any other components.

## Cell geometry

| Item | Value |
|---|---:|
| Cell count | 6 |
| Cell type | 18650 |
| Diameter | 18.3 mm |
| Length | 65.0 mm |
| Arrangement | 2 columns x 3 rows |
| Total cell block width | 63.7 mm |
| Total cell block height | 63.1 mm |

## Layout

- Cells are modeled as six independent cylinders.
- Cell axes run along X.
- The 2-column width is along Y.
- The 3-row height is along Z.
- Column center spacing is 45.4 mm, giving a total outside width of 63.7 mm.
- Row center spacing is 22.4 mm, giving a total outside height of 63.1 mm.
